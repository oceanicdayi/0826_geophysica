# Figure 6. Intensity residual distributions (first vs second school report)

- **Image:** `fig06.png` (the PNG title still says “Figure 7”; in the manuscript this is Figure 6)
- **Section:** 4
- **Official caption:** Intensity residual (predicted minus observed) distributions for the first and second reports. The first report is entirely non-negative.

---

## English

### What is drawn

Two histograms of **intensity error = predicted − observed** at 166 analyst-reviewed stations. Left: first school-channel report (13.67 s, \(M_{Pd}\) 6.6 / 30 km). Right: second report (14.67 s, \(M_{Pd}\) 5.9 / 20 km). The x-axis is integer intensity ranks; the y-axis is percentage of stations.

**First report (left)**

| Residual (ranks) | Share of stations |
| --- | ---: |
| 0 (exact) | 10.2% |
| +1 | 48.8% |
| +2 | 25.3% |
| +3 | 14.5% |
| +4 | 1.2% |
| negative | **none** |

**Second report (right):** exact 27.1%; a few −1 (2.4%); mode still +1 (46.4%). Later reports reach 80.7% within ±1 (Table 2). Within ±1 is 59.0% on the first report and 75.9% on the second.

### How to read it

Positive = **over-warning** (predicted intensity too high). Zero = exact CWA intensity rank. The left histogram having **no negative bar** is the operational fact: nobody was under-warned on the product that PWS/TV also issued in that same second; most stations were over-warned by one to two ranks. One second later the map is already better, but those updates do not go out on PWS/TV.

### Scientific meaning

The \(M_{Pd}\) 6.6 overestimate is not an abstract residual: it maps into **intensity over-alerting**. Combined with Fig. 3, the failure mode is conservative (extra counties, extra ranks). That is preferable to missed warning, but costly for credibility if it repeats. Table 2 is the numerical companion: the message that reached the public is the least accurate of the four school reports.

### Common misreading

These are rank residuals, not PGA residuals. “Exact 10.2%” does not mean the system failed at 90% of sites in an engineering sense; a +1 rank is still a useful, if conservative, warning. Also, the left panel is the *first* report, not a late review — it is what was sent at 13.67 s.

## 中文

### 圖面內容

166 個分析師測站的**震度殘差（預測 − 實測）**直方圖。左：學校通道第 1 報（13.67 s，\(M_{Pd}\) 6.6／30 km）。右：第 2 報（14.67 s，\(M_{Pd}\) 5.9／20 km）。橫軸為整數震度級，縱軸為測站百分比。PNG 標題仍寫 Figure 7；稿件中此為圖 6。

**第 1 報（左）**

| 殘差（級） | 測站占比 |
| --- | ---: |
| 0（完全正確） | 10.2% |
| +1 | 48.8% |
| +2 | 25.3% |
| +3 | 14.5% |
| +4 | 1.2% |
| 負值 | **無** |

**第 2 報（右）：** 完全正確 27.1%；少量 −1（2.4%）；眾數仍是 +1（46.4%）。後續報 ±1 達 80.7%（表 2）。首報 ±1 為 59.0%，第 2 報 75.9%。

### 如何判讀

正值＝**過度預警**（震度報太高）。0＝震度級完全正確。左圖**沒有負柱**：與 PWS／電視同一秒發出的那則，沒有任何站被低估，多數高 1～2 級。一秒後圖已經變好，但 PWS／電視不發這些更新。

### 科學意義

\(M_{Pd}\) 6.6 高估會變成**震度多報**。搭配圖 3，失敗方向是保守（多縣市、多震級），比漏報好，但反覆發生會消耗公信力。表 2 是數字版：公眾拿到的是四則學校報裡最不准的那一則。

### 容易讀錯的地方

這是震度級殘差，不是 PGA 殘差。「完全正確僅 10.2%」在工程上不代表九成失效；+1 級仍是有用、只是偏保守的警報。左圖是 *13.67 秒當時發出的* 第一報，不是事後檢討。
