# Figure 8. Reported magnitude tracks assumed hypocentral distance

- **Image:** `fig08.png`
- **Section:** 5
- **Official caption:** Evidence that reported magnitude tracks assumed distance. (a) Two solutions computed in the same second from identical \(Pd\) values. (b) Magnitude and location error report by report for a geometric-centre stream. (c) All 83 solutions, \(r=-0.74\). (d) Recovered operational relation, 2065 single-station records, rms 0.13.

---

## English

### What the figure shows

Four panels that prove **\(M_{Pd}\) is a deterministic function of \(Pd\) and assumed \(R\)**, not an independent magnitude.

**(a)** Same second, same stations, **identical \(Pd\)**. Red bars: Geiger (offshore, \(R\) ~54–60 km) → station \(M_{Pd}\) ~6.2–6.6, event 6.55. Blue bars: geometric-centre (inland, \(R\) ~15–21 km) → ~5.4–5.7, event 5.66. Difference 0.89 ≈ \(1.85\log_{10}(60/21)=0.84\).

**(b)** One geometric-centre stream, report by report: when location error collapses, **magnitude jumps** (5.46 → 6.42); when the epicentre drifts inland again, magnitude falls.

**(c)** All 83 solutions: epicentral error vs \(M_{Pd}\), \(r=-0.74\), slope −0.15 mag units per 10 km. The regression crosses \(M_L\) 5.85 near **~30 km error** — the “most accurate” magnitudes are the badly inland ones.

**(d)** Predicted vs reported single-station \(M_{Pd}\) on the 1:1 line:  
\(M_{Pd}=4.79+1.16\log_{10}(Pd)+1.85\log_{10}(R)\), \(n=2065\), rms 0.13.

### How to read it

The **apparently good** \(M\) 5.66 solution in (a) is the **wrong location**. The correctly located Geiger solution overestimates. Ranking by magnitude error alone would promote the worst epicentres.

### Scientific meaning

This is **bias term 1 (distance)**. Offshore mislocation is toward the network → smaller \(R\) → smaller \(M\). Fixing location **raises** \(M\) into the overestimate set by terms 2 and 3. Quality control must score location and magnitude **jointly**.

## 中文

### 圖面內容

四聯圖證明 **\(M_{Pd}\) 是 \(Pd\) 與假設距離 \(R\) 的確定函數**。

**(a)** 同一秒、同一批站、**相同 \(Pd\)**。紅：Geiger（外海 \(R\) 約 54–60 km）事件規模 6.55；藍：幾何中心（陸上 \(R\) 約 15–21 km）5.66。差 0.89 ≈ \(1.85\log_{10}(60/21)=0.84\)。

**(b)** 一條幾何中心串流逐報：定位誤差一下降，**規模就跳升**（5.46→6.42）；震央再漂回陸上，規模又掉。

**(c)** 全部 83 筆解：震央誤差對 \(M_{Pd}\)，\(r=-0.74\)。迴歸在誤差約 **30 km** 穿過 \(M_L\) 5.85——「規模看起來最準」的解，定位最差。

**(d)** 單站預測對上報值落在 1:1 線：\(M_{Pd}=4.79+1.16\log_{10}(Pd)+1.85\log_{10}(R)\)，2065 筆，rms 0.13。

### 如何判讀

(a) 裡看起來準的 5.66 **是錯位置**。位置對的 Geiger 反而高估。只靠規模誤差排序，會選到最差震央。

### 科學意義

這是高估的**第一項：距離**。外海錯位朝向測站網 → \(R\) 變小 → \(M\) 變小。位置一改對，\(M\) 升高，再疊上輻射與路徑項。品質管制必須**定位與規模一起看**。
