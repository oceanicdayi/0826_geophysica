# Figure notes / 圖件說明

Bilingual notes from a panel-by-panel reading of every figure in the repository root, cross-checked against `taitung_offshore_eew_manuscript.md`. Each file covers what is drawn, how to read it, what claim it carries, and a common misreading.

本目錄依倉庫根目錄圖檔逐張判讀，並對照稿件 `taitung_offshore_eew_manuscript.md`。每份檔案含：圖面畫了什麼、怎麼讀、支持什麼論點、以及容易讀錯的地方。

All magnitudes discussed in these notes are the operational \(M_{Pd}\). The paper does not analyse \(M_{tc}\) or \(M_{all}\).

本說明一律只討論作業規模 \(M_{Pd}\)，不論 \(M_{tc}\) 或 \(M_{all}\)。
